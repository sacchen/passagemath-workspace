# Fix `weighted_adjacency_matrix(vertices=True)` crash for non-integer weights

_Good for someone comfortable with Python and linear algebra. No Cython or C required._

```bash
uv venv .venv && uv pip -p .venv install passagemath-graphs
```

## The bug

`weighted_adjacency_matrix(vertices=True)` should return a free module endomorphism — a linear map whose rows and columns are labeled by vertex names instead of integers. It crashes for any non-integer weights:

```python
from sage.graphs.graph import Graph

G = Graph(sparse=True, weighted=True)
G.add_edges([('A', 'B', 1.5), ('B', 'C', 2.5), ('A', 'C', 0.5)])
G.weighted_adjacency_matrix(vertices=True)
# TypeError: dense iteration is not supported for sparse input
```

Integer weights (`1`, `2`, `3`) work by accident because Sage's integer matrix class handles sparse dicts internally. Float, `RDF`, `QQ`, and any other ring type hit the crash. The fix should make all weight types consistent.

## Root cause

In `src/sage/graphs/generic_graph.py`, `weighted_adjacency_matrix` ends with:

```python
from sage.matrix.constructor import matrix
if base_ring is None:
    M = matrix(self.n_vertices(), D, sparse=sparse, **kwds)
else:
    M = matrix(base_ring, self.n_vertices(), D, sparse=sparse, **kwds)
return M
```

When `vertices=True`, `**kwds` contains `row_keys`/`column_keys` — these tell the matrix constructor to build a free module morphism instead of a plain matrix. Free module morphisms are built on top of dense matrices. But `sparse=True` (the method's default) causes the dict `D` to be classified as sparse input. Most dense matrix backends then try to iterate it densely and crash.

Compare `adjacency_matrix` nearby (line ~2483): it passes `matrix(base_ring, n, n, D, ...)` with both dimensions explicit, and sets `sparse=False` for graphs under 256 vertices — which is why `adjacency_matrix(vertices=True)` works.

## The fix

In the matrix construction block above, add one guard before the `if base_ring` branch and pass `n, n` explicitly:

```python
from sage.matrix.constructor import matrix
n = self.n_vertices()
if row_column_keys is not None:
    # Free module morphisms require a dense underlying matrix
    sparse = False
if base_ring is None:
    M = matrix(n, n, D, sparse=sparse, **kwds)
else:
    M = matrix(base_ring, n, n, D, sparse=sparse, **kwds)
return M
```
